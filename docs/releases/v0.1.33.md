# v0.1.33 Release Notes

## Highlights

- Permission requests now stay visible directly above the composer while an
  agent is paused, so long output can no longer hide the action that is blocking
  the turn.
- Approval controls and status copy now follow the selected DCC language,
  including Brazilian Portuguese labels for allowing and denying requests.
- CodeRabbit can now be shown or hidden in the Inspector independently from its
  CLI login, and the Settings screen can disconnect the local CLI account.
- The workspace rail and Inspector were tightened to surface the most useful
  state with less visual noise.

## Permission Requests

- Pending approval cards move out of the scrollable conversation and into a
  dedicated amber panel immediately above the composer.
- The panel clearly states that the agent is paused, keeps `Allow` and `Deny`
  available without scrolling, and shows a count when more than one request is
  pending.
- Active requests are rendered only once. After a decision, the panel
  disappears and the resolved card remains in its original place in the thread
  history.
- The panel has its own bounded scrolling area for unusually large or multiple
  requests and announces its arrival to assistive technology.
- Approval labels, tool, command, file, pending/resolved states, error messages,
  and actions are localized in English and Brazilian Portuguese.

## CodeRabbit Controls

- Added a persistent **Show in Inspector** preference to hide CodeRabbit review
  prompts, summaries, panels, and file annotations without logging out or
  deleting review history.
- Disabled integrations no longer run the Inspector's CodeRabbit status,
  history, or fingerprint queries.
- Added **Disconnect** to run the CodeRabbit CLI logout flow, refresh connection
  state, and disable the Inspector integration.
- Added the logout command to the Rust/Tauri boundary and regenerated the
  TypeScript contracts.

## Workspace and Inspector UX

- Refined workspace rail rows so primary identity, activity, elapsed time, and
  recap information fit into a clearer compact hierarchy.
- Reduced visual competition from row actions and metadata while preserving
  attention colors for states that need user action.
- Reorganized Inspector disclosure and CodeRabbit visibility so disabled
  integration content does not leave stale annotations or empty review UI.
- Updated the development Tauri resource configuration so the staged sidecar
  vendor resources remain available in development builds.

## Validation Before Publishing

- Run desktop type checks: `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite: `yarn workspace @dcc/desktop test`
- Build the desktop application: `yarn workspace @dcc/desktop build`
- Build the mobile web application: `yarn workspace @dcc/mobile-web build`
- Run the Rust workspace tests: `cargo test --workspace`
- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.33` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
