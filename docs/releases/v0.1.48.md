# v0.1.48 Release Notes

## Safer, more accurate commit messages

- Generate commit suggestions exclusively from the staged Git snapshot so task,
  workspace, and conversation text cannot leak into commit history.
- Add a reviewable commit-message preview with editable subject and body before
  committing or committing and pushing from the workspace.
- Reject stale previews by fingerprinting the staged changes and verifying the
  exact snapshot again at commit time.
- Fall back to deterministic, path-based conventional commit messages when an AI
  provider is unavailable or returns an invalid suggestion.
- Keep single- and multi-workspace delivery flows synchronized after staging,
  committing, and pushing.

## Clearer conversation timeline

- Project each structured provider turn into one stable assistant row while
  keeping commentary, reasoning, tools, and delegated-agent activity together.
- Stream commentary inside the activity disclosure and reveal the final answer
  in the main response area when the provider identifies it.
- Merge repeated native-subagent updates by their stable identity and preserve
  the first visible identity used by the timeline.
- Ignore delayed assistant, reasoning, and tool deltas after their lifecycle has
  completed so settled messages do not reopen or appear twice.
- Expand timeline coverage for live, restored, interrupted, and out-of-order
  provider events.

## Validation before publishing

- Run desktop type checks, the complete desktop test suite, and the production
  desktop build.
- Run Rust formatting, workspace checks, and the complete Rust test suite.
- Confirm release metadata is `0.1.48` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts, inspect the
  draft release and `latest.json`, then publish only after manual verification.
