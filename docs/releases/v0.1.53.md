# v0.1.53 Release Notes

## DCC Usage

- Add a provider arena that compares real activity recorded by DCC using token
  share when exact telemetry is available and completed turns otherwise.
- Add period and current-project filters, summary metrics, a daily activity
  timeline, provider scorecards, and a model leaderboard.
- Capture exact per-turn token telemetry from Codex and Claude, including input,
  output, cache, reasoning, and provider-reported cost fields when available.
- Keep providers without token telemetry in the comparison using their real DCC
  sessions and completed turns.

## Performance and persistence

- Store compact per-turn model totals outside session transcripts and search
  indexes, replacing duplicate provider notifications instead of accumulating
  them.
- Aggregate dashboard data in SQLite only when the panel is opened or its
  filters change.
- Load the dashboard as a separate frontend chunk and render charts with CSS
  plus one SVG path per provider, without polling or a charting dependency.
- Use a partial index containing only completed-turn events to minimize ongoing
  database write and storage overhead.

## Skills layout

- Keep long skill paths and externally detected skill inventories contained
  inside the dialog at smaller window sizes.

## Validation before publishing

- Pass the complete desktop test suite with 466 tests, desktop type checks, and
  the production frontend build.
- Pass the full Tauri/Rust compilation and focused provider telemetry and SQLite
  aggregation tests.
- Confirm release metadata is `0.1.53` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create the
  GitHub draft release for final publication.
