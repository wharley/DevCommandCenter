# v0.1.11 Release Notes

## Highlights

- Added a workspace recap strip to the inspector so the current Git/session
  state and the next suggested action stay visible while working.
- Fixed tool-call disclosure behavior so live and failed calls open
  automatically, but user toggles are respected after manual interaction.
- Improved GitLab change request creation and authentication parsing for `glab`
  status output.

## Inspector And Workflow

- Summarized changed files, insertions, deletions, remote-ahead state, conflicts,
  PR/MR state, and pending CodeRabbit findings into a single recap sentence.
- Wired recap actions into the existing commit, continue-workspace, activity,
  and review flows without adding extra CodeRabbit review requests.
- Added localized recap and conversation labels for English and Brazilian
  Portuguese.

## Providers And GitLab

- Updated Claude Sonnet aliases to resolve to `claude-sonnet-5` across the
  desktop and Rust model registries.
- Allowed Claude Sonnet 5 to use the full effort range where supported.
- Hardened GitLab token extraction for marked `glab auth status` lines and
  ignored masked token values.
- Made GitLab MR creation non-interactive by passing closed stdin and `--yes`.

## Validation Before Publishing

- Typecheck the desktop app: `yarn workspace @dcc/desktop typecheck`
- Build the desktop frontend: `yarn workspace @dcc/desktop build`
- Confirm release metadata is `0.1.11` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
