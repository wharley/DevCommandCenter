# v0.1.69 Release Notes

## Clearer provider errors

- Show the complete message returned by the provider when execution fails,
  including errors wrapped in JSON responses.
- Keep the original error details available to expand and copy for troubleshooting.
- Preserve the provider's explanation without guessing whether the cause is a
  subscription restriction, a usage limit, or another request failure.

## Smoother conversation startup

- Show preparation steps inside the conversation as soon as the first prompt is
  submitted, with animated icons and completed-step checkmarks.
- Keep those steps visible while the session is created, the message is sent,
  and the agent begins responding. Early session-list updates no longer bring
  back the centered task launch screen.
- Reveal the first prompt in its final timeline position when agent activity
  arrives, avoiding a jump between the centered launch screen and the conversation.
- Replace the internal session-start event and UUID with preparation text in
  the selected language, including Portuguese and English.
- Preserve existing conversation history when sending follow-up prompts.

## Validation

- All 730 desktop tests passed.
- Desktop TypeScript checking, the production frontend build, and workspace-wide
  `cargo check` passed.
- Browser checks covered the launch-to-preparation transition, early session
  discovery, stable preparation steps, first agent activity, both languages,
  light/dark themes, and compact layouts.
- Manual development testing confirmed the corrected first-prompt transition.
- Signed release artifacts remain subject to CI verification and installed-app
  validation before publication.

## Updating

Use the in-app updater after publication, or download the package for your platform.
Existing projects and conversations remain in place; a clean installation is not
required.
