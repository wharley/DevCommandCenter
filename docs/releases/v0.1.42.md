# v0.1.42 Release Notes

## Long-running Memory Stability

- Release terminal output buffers, listeners, PTY routing, and runtime entries
  when a terminal tab or its workspace is permanently closed.
- Safely dispose terminals even when their PTY is still being created, avoiding
  late processes and retained output after a rapid close.
- Preserve exited terminal output and restart behavior while the owning tab
  remains open.

## More Selective Query Retention

- Keep lightweight workspace and provider metadata warm for fast navigation.
- Shorten inactive retention for reloadable session histories, file contents,
  diffs, job logs, and search results.
- Preserve the existing bounded offline cache and restart behavior independently
  from in-memory garbage collection.

## Lighter Editor Surfaces

- Unmount clean inactive file surfaces so their query observers and duplicated
  file payloads can leave the WebView heap.
- Keep dirty and saving tabs mounted to preserve unsaved edits, conflict
  reconciliation, and in-flight writes.
- Remove editor state left behind when a preview tab is replaced while retaining
  cursor restoration for normal tab switches.

## Validation Before Publishing

- Run desktop type checks:
  `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite:
  `yarn workspace @dcc/desktop test`
- Build the desktop and mobile clients:
  `yarn workspace @dcc/desktop build` and
  `yarn workspace @dcc/mobile-web build`
- Run the Claude sidecar test suite:
  `yarn --cwd sidecar test`
- Run core, provider, infrastructure, and Tauri library tests:
  `cargo test -p dcc-core`, `cargo test -p dcc-providers`,
  `cargo test -p dcc-infra`, and `cargo test -p dcc-tauri --lib`
- Check Rust formatting:
  `cargo fmt --all -- --check`
- Confirm release metadata is `0.1.42` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
- Let the release workflow build, sign, and package Linux and macOS artifacts;
  review every draft asset and `latest.json` before publishing.
