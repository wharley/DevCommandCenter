# v0.1.58 Release Notes

## Agent workbench and continuous review

- Introduce a split workbench with a unified command palette and a calmer
  Changes workspace for moving between conversation, files, and review.
- Review live and completed-turn changes inline, with a continuous diff feed,
  expandable file inspection, colored captured patches, and restored annotation
  actions in review cards.
- Unify review scopes and actions, keep annotation controls usable above the
  inspector, and streamline the path from the composer into change review.

## Last Turn Review and Guarded Undo

- Preserve immutable snapshots for completed agent turns and ship Guarded Undo
  as a macOS beta for eligible tracked files modified in place.
- Verify filesystem, Git, worktree, index, and artifact identity before capture,
  preview, and restoration; unsupported or changed state continues to fail
  closed without weakening the safety contract.
- Coordinate turn capture with workspace, delivery, delegation, and shared Git
  mutations, including cancellation-safe runtime ownership and startup recovery.
- Support stable detached task worktrees and common atomic editor saves while
  continuing to reject permission, metadata, link, filter, and index drift.
- Explain specific ineligibility reasons in English and Brazilian Portuguese,
  safely retire terminal Undo history with deleted workspaces, and block
  deletion while an Undo recovery is active.
- Add a user-facing Guarded Undo guide and refresh the architecture and README
  documentation with the current product workflow.

## Task launch and lifecycle reliability

- Centralize the New task entry point, simplify launch context, remove the
  optional setup ritual, and remember the last selected project for the next
  task while preserving explicit project context.
- Make delegation apply and worktree cleanup recoverable after interrupted
  operations, and harden workspace and remote-branch deletion across partial
  failures and already-missing worktrees.
- Share terminal and process runtimes by physical scope, enforce durable
  terminal uniqueness, and make terminal and capture ownership cancellation
  safe.
- Preserve branch tracking after exact pushes and refresh authoritative
  workspace state after deletion attempts so retries use current Git state.

## Validation before publishing

- Pass the complete desktop test suite with 539 tests, desktop type checks, and
  the production frontend build.
- Pass the complete Rust workspace test suite and Rust formatting checks; only
  explicitly authenticated, opt-in external-service smokes remain skipped.
- Confirm the release diff has no whitespace errors.
- Confirm release metadata is `0.1.58` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create the
  GitHub draft release for final publication.
