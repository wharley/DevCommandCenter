# v0.1.90 Release Notes

## Project memory

- Redesign the recovered sources menu (the brain icon in the chat header).
  A header says what the list is: what the agent received from the
  project's memory on its latest turn. Each source gets one kind tag (your
  prompt, agent answer, page), a short date, and quiet Pin / Correct /
  Ignore actions instead of an always-open input per card.
- A correction opens an editor on demand and shows as the version the
  agent receives. Pins, corrections and ignores can be undone, and ignored
  sources stay reachable behind a footer toggle.
- Pinned, corrected and ignored sources now shape the next injection
  instead of only the menu: they reorder or rewrite what the project's own
  query returned and never pull in other memory.
- Show each recovered source once. The same prompt sent twice used to come
  back as identical pairs, listing every source twice and spending half of
  the injected memory on repeats.
- Export events with their real time, keep long agent answers inside the
  server's 2 KB cap with their opening and conclusion, and keep dropped
  events out of the accepted count.

## ai-memory sidecar

- Bundle ai-memory v2.6.1. Existing stores migrate on first start; the
  database is copied to `backups/before-<version>/` first, since migrations
  are one-way.
- The managed sidecar no longer inherits `AI_MEMORY_*` variables from the
  shell (LLM providers and keys included) and keeps per-project memory
  isolated: the cross-project profile, handoffs on every session end, the
  background auto-improve job and English-only stopwords stay off.
- Stop the sidecar with SIGTERM before killing it.

## Sidebar

- Recent projects with no active task wait behind one collapsible
  "N projects without tasks" line at the end of Recent. Pinned projects
  always stay.
