# v0.1.78 Release Notes

## Workspace and local branch workflow

- Add branch discovery and selection for **Local direto** tasks.
- Preserve the active local branch for local-direct work and keep protected
  worktree branch creation isolated to the workflows that require it.
- Improve the local branch selector with clearer interaction feedback and a
  pointer cursor.

## Provider catalog

- Update the Grok catalog to Grok 4.7, including aliases and `xhigh` effort
  support.

## Release infrastructure

- Add validated OJ binary caching for release builds and a workflow that warms
  the cache across supported runners.

## Validation

- `git diff --check` passed for the release changes.
- GitHub Actions are enabled and the release workflow is configured to publish
  tagged releases as drafts.
