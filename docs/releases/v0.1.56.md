# v0.1.56 Release Notes

## Running tasks across projects

- Surface active agent tasks from every project in a dedicated Running section
  at the top of the sidebar, ordered by the most recently started execution.
- Show each task with its project identity, elapsed activity time, and a direct
  action to reopen the workspace without navigating through project groups.
- Keep the overview compact by showing four tasks initially, with controls to
  expand or collapse the remaining activity and localized labels in English and
  Brazilian Portuguese.
- Align elapsed-time labels consistently when task and project names wrap or
  use different amounts of vertical space.

## Semantic workspace branches

- Derive readable `dcc/` branch names from workspace or change-request titles
  when a detached worktree is first pushed or prepared for a pull request.
- Classify clear fixes and features into `dcc/fix/` and `dcc/feat/` branches,
  normalize accented Portuguese titles, and keep ambiguous titles in the flat
  `dcc/<slug>` form.
- Preserve existing user branches and technical worktree paths, fall back to
  the established path-based naming when the title is provisional, and choose
  the next available name when a semantic branch already exists.

## Validation before publishing

- Pass the complete desktop test suite with 475 tests, desktop type checks, and
  the production frontend build.
- Pass Rust compilation and the focused semantic-branch tests.
- Confirm the release diff has no whitespace errors.
- Confirm release metadata is `0.1.56` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create the
  GitHub draft release for final publication.
