# v0.1.74 Release Notes

## Provider usage and workspace visibility

- Show provider icons on workspace task rows so active work is easier to scan.
- Display the next account-usage reset time in provider menus and Settings.
- Add provider reset-credit data and a confirmation flow for consuming eligible
  Codex usage resets, with refreshed usage state after the reset.
- Accept provider reset timestamps in both numeric and string formats.

## Native provider orchestration

- Expand the DCC orchestration skill to Claude Code, Codex, Gemini CLI, Cursor,
  and Grok native skill targets.
- Guide agents to use only the subagent roles exposed by the active provider,
  preserve the current checkout and execution environment, and consider the
  cost and coordination overhead of delegation.
- Allow existing catalog skills to be reviewed and updated without losing
  project-specific agent selections or invocation preferences.
- Document the generated skill formats, legacy AGENTS.md behavior, and provider
  orchestration boundaries in `docs/SKILL_PRESETS.md`.

## Reliability and composer fixes

- Capture frontend errors locally and provide recovery screens with a
  copyable diagnostic report and reload action at app and workspace scope.
- Stabilize the composer link popover anchor while streamed content changes.
- Keep provider icons deduplicated in the workspace sidebar.

## Validation

- Desktop type checking passed.
- All 43 sidecar tests passed.
- Workspace-wide `cargo check --locked` passed with the existing unreachable-code
  warning in the restart command.
- The desktop suite passed 887 tests; one unrelated
  `computer-use-approval-host.test.tsx` permission-button expectation remains
  environment-sensitive and is tracked separately.
- `git diff --check` passed.
- Signed macOS artifacts and updater metadata remain subject to the workflow's
  release checks before publication.

## Updating

Use the in-app updater after publication, or download the package for your
platform. Existing projects, conversations, and skill customizations remain
in place; review preset updates before saving them to a project.
