# v0.1.99 Release Notes

## Download a DMG on macOS

- Each release now ships a notarized `.dmg` for Apple Silicon and Intel:
  open it, drag Dev Command Center to Applications and launch it. Updates
  keep arriving through the app as before, however it was installed.
- `releases/latest/download/Dev.Command.Center_aarch64.dmg`,
  `..._x64.dmg` and `..._amd64.deb` always point at the newest installer.

## One task list in the sidebar

- The rail lists every active task together, whatever its project, ordered
  by your own interaction and split into Pinned / Today / Yesterday / This
  week / Older. Each row shows the project's animal (animated while the
  agent runs) and reads project · model · state.
- "N running" is a button: each click scrolls to the next running task.
- Resident agents sit in one row of avatars; a dot marks the one that needs
  you or has a result you have not opened.
- A right click on a task opens the project menu the folder header used to
  hold.

## Child tasks stay out of the way

- A child task the agent starts edits the parent's checkout directly, like a
  Claude Code subagent: no review card and no apply card. Only one child
  edits at a time.
- What you ask for stays with the parent task. The agent proposes a child
  only when you ask to split work off, and a child's status no longer
  proposes a chain of review and fix tasks.
- Deleting a task frees its child worktrees without losing edits that never
  reached the parent; those block the delete and can be discarded on
  purpose.
- Untracked files (reports, build output) no longer stop a worktree task
  from starting.

## Lighter on disk

- The database gives freed space back: an existing database converts once
  at startup (448 MB to 128 MB on a real one), streamed chunks of settled
  turns are merged, the WAL file shrinks back after bursts, and a duplicate
  index is gone.
- Streaming no longer reindexes the whole session on every chunk, and
  opening a session no longer rebuilds the search index.
- The built-in browser's cache is trimmed above 500 MB (logins stay);
  Settings > General shows its size with Clear cache and Clear everything.
- Liberar espaço also lists DCC's own data (database, browser cache, webview
  storage), and Compactar reclaims it now.
- localStorage is written only when something changed, instead of growing
  to hundreds of megabytes.

## Starting a conversation

- The prompt you send shows at once, and a live row says what is happening
  (routing, starting the provider, connecting MCP servers, waiting for the
  first response) with a clock that carries into the reply.
- The agent's work replaces that row as soon as it starts, instead of
  sitting below a second copy of the prompt.

## Fixes

- A task shows the model it runs on, never the previous task's.
- A task's Browser never shows another task's page; a closed Browser is
  released after five minutes.
- The file tree shows gitignored files such as `.env` (dimmed), and a
  worktree's `.env` linked to the main checkout opens.
- After an update, the app replaces the background daemon left running by
  the previous version instead of reusing it; supervised processes are
  resumed.
