# v0.1.18 Release Notes

## Highlights

- Fixed delegation dialog state leaking between workspaces. Opening a delegation
  in a different workspace now starts without the previous workspace's plan
  instruction or transient delegation state.
- Reset transient composer and review state when switching workspaces, preventing
  cross-workspace UI context from being reused.

## Validation Before Publishing

- Run desktop type checks: `yarn workspace @dcc/desktop typecheck`
- Run plan follow-up tests:
  `yarn workspace @dcc/desktop test --run src/features/panel/plan-follow-up.test.ts`
- Confirm release metadata is `0.1.18` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
