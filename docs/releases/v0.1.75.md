# v0.1.75 Release Notes

## Project memory and session continuity

- Add project-scoped AI memory with persistent sources, automatic checkpoints,
  export history, retry handling, and sidecar status visibility.
- Preserve memory across task completion, new sessions, and task deletion while
  keeping scopes isolated between projects.
- Recover and display memory sources in sessions, with controls for reviewing
  and curating recovered context.
- Add configuration, attribution, feasibility, and operational guidance for
  the bundled AI memory sidecar.

## Chat and workspace experience

- Show startup progress when opening a new chat and simplify the live activity
  timeline by collapsing it by default.
- Improve the session header, memory history, source presentation, and
  advanced settings for a clearer conversation workflow.
- Preserve workspace branch context when creating tasks and keep memory export
  history available after task deletion.

## Reliability and release preparation

- Harden memory ingestion, export retries, database persistence, sidecar
  lifecycle handling, and session command coordination.
- Add the AI memory sidecar to release resources and update the local
  development/build orchestration for the new runtime.
- Document third-party notices and the AI memory product readiness criteria.

## Validation

- All 888 desktop tests passed, including the AI memory, session continuity,
  startup progress, and activity timeline coverage.
- All 43 sidecar tests passed, and the local MCP release gate passed with the
  focused Rust, sidecar, contracts, and desktop checks.
- Desktop and contracts type checking passed, along with workspace-wide
  `cargo check --locked`.
- `git diff --check` passed for the release changes.
- Signed macOS artifacts and updater metadata remain subject to the workflow's
  release checks before publication.

## Updating

Use the in-app updater after publication, or download the package for your
platform. Existing projects, conversations, and skill customizations remain
in place.
