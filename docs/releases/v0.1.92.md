# v0.1.92 Release Notes

## DCC on your phone, from any network

- The desktop now reaches a paired phone through an outbound connection to a
  relay (`wss://relay.devcommandcenter.com`, self-hostable from `apps/relay`).
  The channel is end-to-end encrypted with Noise: the relay only forwards
  ciphertext. No Tailscale, port forwarding, account or same Wi-Fi needed.
- Pairing: Settings → Connections → "Pair via relay" shows a five-minute,
  single-use QR code; the desktop asks to approve the device and both sides
  show the same fingerprint. Revoking a device drops its connection at once.
- The native companion app (`apps/mobile`, Expo) lists agents and workspaces,
  streams threads live, answers permissions and questions, stops agents,
  starts new tasks (project, agent, model, worktree and access level), takes
  photo and file attachments, dictation, and `@` file mentions.
- Push notifications when a task needs you or finishes, with generic text
  only ("<project> precisa de você"); nothing is sent while you are using the
  desktop or the app is open.

## Desktop

- The HTTP API is served by the desktop itself on `127.0.0.1` only, on the
  same session runtime as the window, so the phone sees and answers the
  sessions you start on the desktop. The first answer to a permission wins.
- Tasks and turns from the phone keep the chosen access level; turns without
  one inherit the session's last level.
- Delivery offers update-and-push when the remote branch moved ahead.
- Includes the v0.1.91 ai-memory startup hotfix.

## Security

- The local API no longer listens on the network and generates a random API
  key on first run; the old public default key is refused.
- The legacy mobile web app, LAN/PIN pairing and 30-day bearer tokens are
  removed. Devices paired that way are revoked once (`legacy_device_retired`
  in the audit log); pair again through the relay.

## Validation

- All 1125 frontend tests passed; desktop TypeScript checks passed.
- Rust workspace tests passed except the three known `dcc-mcp-fixture`
  failures, unrelated to this release.
- The relay end-to-end test (`yarn test:remote:e2e`) passed: pairing,
  reconnect, cursor streaming, revocation and a ciphertext-only relay dump.
- Exercised on a real Android phone over 4G against the published relay.
