# v0.1.50 Release Notes

## Multi-project chats no longer wait for optional setup

- Allow multi-project conversations to start while one or more project
  workspaces still have recommended setup pending.
- Keep dependency installation and build preparation optional, matching the
  existing behavior of single-project tasks.
- Continue blocking conversations for workspaces that are still initializing,
  archived, or completed.
- Preserve validation of DCC-managed worktree paths and distinct project roots
  before starting a multi-project session.
- Add regression coverage for pending setup, unavailable lifecycle states, and
  invalid managed worktree paths.

## Validation before publishing

- Run desktop type checks, the complete desktop test suite, and the production
  desktop build.
- Run Rust formatting, workspace checks, and the complete Rust test suite.
- Confirm release metadata is `0.1.50` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts, inspect the
  draft release and `latest.json`, then publish only after manual verification.
