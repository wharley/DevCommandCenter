# v0.1.76 Release Notes

## Jev decision provider

- Add model routing preflight and configurable decision points for more
  deliberate provider selection.
- Add skill routing, tool guards, completion review actions, persisted
  completion decisions, and a decision history view.
- Improve decision quality and expose route and evaluation details in the
  conversation experience.

## Settings and workspace experience

- Separate memory configuration from export history and split decision history
  into its own settings tab.
- Preserve routed composer submissions cleanly and improve the desktop agent
  activity disclosure by simplifying the live activity presentation.
- Migrate the desktop and mobile web builds from Vite to OJ and update the
  related build, type, and bundling configuration.

## Validation

- All 888 desktop tests passed.
- All 43 sidecar tests passed after applying the repository's pinned
  `mcp-remote` post-install compatibility patch.
- The local MCP release gate passed, including 37 core, 22 infrastructure,
  159 provider, 16 fixture, 6 Tauri, 31 sidecar, 18 focused desktop, and
  supporting type-check tests.
- Desktop, mobile web, and contracts type checking passed, along with
  workspace-wide `cargo check --locked`.
- `git diff --check` passed for the release changes.
- Signed macOS artifacts and updater metadata remain subject to the workflow's
  release checks before publication.

## Updating

Use the in-app updater after publication, or download the package for your
platform. Existing projects, conversations, and skill customizations remain
in place.
