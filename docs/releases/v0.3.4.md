# v0.3.4 Release Notes

## Connectors

- Resend connects in one click: agents can send emails, and read your
  domains, contacts and broadcasts.
- Trello connects in one click through Atlassian's own Trello server: boards,
  lists and cards. It archives, never deletes.
- Agents can send Slack messages, mentions included. Each message goes out in
  your name after you approve it. If you created the Slack app before this
  version, add `chat:write` under OAuth & Permissions → User Token Scopes,
  reinstall the app and reconnect; Slack's steps in DCC say so.
- Reconnecting a catalog connector asks for the permissions DCC uses today,
  not the ones stored when it was first connected.
- Slack's Client ID step links to your Slack apps, for when the id is long
  lost.

## Fixes

- The connect dialog never grows past the window: its middle scrolls and the
  continue button stays at the bottom.
