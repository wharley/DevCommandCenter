# v0.3.3 Release Notes

## Keeping a task's branch up to date

- "Puxar alterações" brings in the commits someone else pushed to your task's
  branch. The branch is fetched when the task opens; while it is behind, the
  step leads the header and the branch bar reads "Puxar · N atrás". It
  rebases only onto the branch's own remote copy and merges otherwise, so
  commits you already pushed are never rewritten.
- "Atualizar branch" is now "Atualizar com a base": it merges the base into
  your branch, as before.
- A new task starts from the base as the remote has it when your local copy
  is behind. Opening "Nova tarefa" fetches each project's base in the
  background, so creating a task never waits on the network.

## Failing checks inside DCC

- While a GitHub pull request's checks fail, Mudanças shows each failed job
  with the log of the step that broke.
- "Corrigir CI" puts the request, with those errors, in the composer instead
  of opening the browser.
- A pull request waiting on a review or a repository rule, or in conflict with
  its base, is no longer called "checks falhando".

## Connectors

- Eight more connect in one click: Supabase, Vercel, Cloudflare (Workers, KV,
  R2, D1), Neon, Netlify, PostHog, RevenueCat and Atlassian (Jira,
  Confluence).
- ClickUp connects again: the long client id it issues was being cut short.

## Sidebar

- Tasks whose agent is working come first in each day.

## Fixes

- A pull request review draft no longer stops with "requested an interactive
  or mutating action": Claude and Codex run it read-only, and anything that
  would ask is declined while the review goes on.
- The ✨ draft no longer ends with "Generated with Claude Code" or other
  agent trailers: the text goes out in your name.
- A long ✨ draft scrolls inside its field instead of stretching the pull
  request or commit dialog.
- The connect dialog's texts wrap inside it.
