# v0.1.46 Release Notes

## Pull request workspace flow

- Finish the pull request workspace creation flow without keeping the action in a
  loading state after the workspace has been created.
- Select the new workspace and return to the Composer immediately while refreshing
  workspace and pull request data in the background.

## Composer context isolation

- Prevent terminal-derived Composer context from leaking into another workspace.
- Clear terminal prefill state when switching workspaces.
- Consume external Composer prefills after they are applied so the same context is
  not replayed on later renders.
- Keep terminal context tied to the workspace where it was collected.

## Validation before publishing

- Run desktop type checks and the complete desktop test suite.
- Run Rust formatting and the relevant Tauri workspace checks.
- Confirm release metadata is `0.1.46` in the root package, sidecar, Cargo, and
  Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts, inspect the draft
  release and `latest.json`, then publish only after manual verification.
