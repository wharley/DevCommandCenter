# v0.1.61 Release Notes

## Integrated browser and agent control

- Add a native browser surface that can run beside the chat, follow detected
  local development servers, and keep its bounds and visibility synchronized
  with the workbench across layout changes.
- Let people send bounded page context to the agent and grant explicit,
  short-lived permission for anchored semantic browser actions.
- Capture page, console, network, and resource evidence through deliberate
  gestures, with redaction, limits, safe workspace locations, and a trusted
  local audit trail.
- Harden browser lifecycle, address handling, native WebView occlusion, and
  macOS title-bar positioning.

## Evidence-first debugging

- Collect Browser, Terminal, and diff findings in one reviewable composer tray
  instead of inserting raw evidence directly into the prompt.
- Organize evidence as Observe, Reproduce, Investigate, Fix, and Verify; enforce
  item and character budgets and preserve source, trust, and truncation
  metadata without persisting evidence bodies.
- Carry reviewed evidence into direct turns, queued work, steering, and single
  or fan-out delegations, consuming attachment ledger entries only after the
  request is accepted.
- Record bounded evidence metadata on the durable turn and suggest the natural
  next debugging stage after completion.

## Durable objectives and resilient conversations

- Add a task objective with intent, done criteria, turn and failure budgets,
  automatic pause behavior, retry counters, and controls to pause, resume,
  complete, edit, or clear it.
- Re-send the objective as bounded background context on every turn so it
  survives provider switches, compaction, delegation, and application restarts.
- Recover turns orphaned by a dead process, expose explicit Retry and Continue
  actions for interrupted work, and record automatic objective pauses in the
  timeline.
- Fork a new thread from a user message or a completed assistant reply with a
  bounded snapshot, inherited objective, and durable origin metadata.
- Re-anchor a fresh provider runtime from durable history after a cold attach,
  and add in-conversation find with keyboard navigation.

## Provider capabilities and runtime updates

- Centralize provider capability authority in the backend and project it into
  model selection, plan and fast modes, runtime settings, account usage,
  delegation, review, images, and compaction behavior.
- Add persistent provider availability controls and validate dynamic model
  discovery against the runtime instead of accepting unverified model IDs.
- Add `/compact` as a capability-aware composer command and refresh runtime and
  session controls around the registered provider contract.
- Add the Antigravity ACP provider and account flow, update Grok Build to Grok
  4.6, update the bundled Claude Code runtime, and require Node.js 22.12 or newer.
- Reconcile canonical live session envelopes so reconnects and event hydration
  do not duplicate, regress, or lose in-flight activity.

## Help, onboarding, and interaction polish

- Add searchable in-app Help with guides for the major DCC surfaces, contextual
  command-palette entries, bilingual copy, and examples using the real UI
  labels.
- Replace the first-run tour with a focused three-step walkthrough of tasks,
  the workbench, and the composer, then hand off to Help for deeper guidance.
- Document terminal selection and Browser evidence flows, and place Task
  objective directly beside Plan mode in Help so the composer controls are easy
  to discover together.
- Refine agent activity presentation, conversation navigation, runtime controls,
  and workspace state; show “Preparing the agent…” immediately after every
  submitted prompt until real model activity arrives.
- Open detected local servers directly in the integrated Browser and avoid stale
  pull-request completion state in workspace actions.

## Validation before publishing

- Pass the complete desktop test suite with 687 tests, desktop type checks, and
  the production frontend build.
- Pass Rust workspace tests, 26 sidecar tests, the local MCP release gate, and
  Rust formatting checks.
- Confirm the release diff has no whitespace errors.
- Confirm release metadata is `0.1.61` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create
  the GitHub draft release for final verification and publication.
