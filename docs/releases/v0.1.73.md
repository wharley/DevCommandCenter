# v0.1.73 Release Notes

## Authenticated Browser workflows

- Import the current site's session from a Chrome or Arc profile on macOS,
  with an explicit confirmation before importing cookies.
- Support OAuth popups, native browser interactions, and main-document
  navigation tracking for authenticated workflows.
- Handle agent Browser approvals in the conversation and keep requests tied
  to the active browser session.

## External app control and Appshots

- Add experimental macOS app control with explicit, time-limited authorization
  scoped to selected applications. Review permissions and revoke access in
  Settings.
- Attach screenshots of up to six open app windows to a conversation draft on
  macOS 14 or later. Preview and select the windows before attaching them.
- Capture the frontmost app with **Command + Shift + 9**, or customize the
  shortcut in Settings. Captures stay attached to their original draft even
  when switching tasks.

## Rich text composer

- Format text with bold, italic, strikethrough, and inline code. Create and edit
  links with custom labels, and detect URLs automatically when typing or pasting.
- Start bullet and numbered lists by typing a list marker followed by a space.
  Inside a list, Enter adds an item, Enter on an empty item exits the list, and
  **Cmd/Ctrl + Enter** sends the message.
- Preserve formatting, lists, links, and attachments in drafts and convert
  rich text to Markdown when sending.
- Show cached site favicons beside links and in the link menu, with a globe
  fallback when an icon is unavailable.

## Review and deliver changes

- Redesign conversation review cards and open captured changes in a dedicated
  diff preview dialog with clearer file labels and navigation.
- Commit selected changes, push the current branch, and create or open a pull
  request directly from the review dialog.
- Show the live branch's pending changes and ahead/behind state, and recheck
  the branch before delivery actions. Historical previews remain connected to
  their original turn.

## Validation

- All 876 desktop tests passed, including Browser approvals, Appshots, rich
  text, favicon caching, and review delivery coverage.
- All 123 selected Rust tests passed for Browser requests, sessions, popups,
  Appshots, and scoped app control; one native test remains explicitly ignored.
- Desktop TypeScript checking, production desktop and mobile frontend builds,
  and workspace-wide `cargo check --locked` passed.
- Signed macOS artifacts and updater metadata are checked before publication.

## Updating

Use the in-app updater after publication, or download the package for your
platform. Appshots requires macOS 14 or later and Screen Recording permission;
external app control also requires Accessibility permission and an explicit
authorization for the selected apps.
