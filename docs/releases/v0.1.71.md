# v0.1.71 Release Notes

## Favorite model and effort combinations

- Save provider, model, and effort together and apply the combination with one
  selection. Keep multiple favorites for the same model at different efforts.
- Add, edit, remove, and reorder favorites by dragging or using keyboard/arrow
  controls. Favorites are saved on this device and shared across projects.
- Use a compact picker with one line per favorite, effort aligned on the right,
  provider details on hover, and up to eight visible favorites in a scrolling
  list. Model browsing, editing, and execution controls remain below the list.
- Keep the complete catalog under **All models**. Changing the effort for a
  conversation leaves the saved favorite unchanged; unavailable combinations
  remain visible for editing or removal.

## Review changes in the conversation

- Show per-turn review cards in the conversation timeline, with changed files
  and inline diffs connected to the corresponding agent turn.
- Select lines or text in a diff and explicitly add the selection to the chat,
  preserving the current draft and including the file and line context.
- Unify review and Inspector navigation so the selected changes stay connected
  to the active conversation.

## Send and track DCC feedback

- Report bugs, suggest improvements, and follow your reports from the sidebar
  using the GitHub account connected in DCC.
- Review each public issue before publishing. Version and system information
  are optional, and unfinished drafts stay on the device.
- Keep per-account history and recover interrupted submissions without blindly
  creating duplicate issues.

## Fixes

- Consume a note's prefilled prompt before the first session starts, preventing
  the same note from reappearing after sending the first message.
- Refresh provider metadata after CLI updates so new sessions use the updated
  runtime while existing sessions retain their running context.

## Validation

- All 782 desktop tests passed, including favorite selection, editing,
  persistence, and keyboard interaction coverage.
- All 157 provider library tests and all 7 feedback command tests passed.
- Desktop TypeScript checking, production desktop and mobile frontend builds,
  and workspace-wide `cargo check --locked` passed.
- Signed macOS artifacts and updater metadata are verified by the release
  workflow before publication.

## Updating

Use the in-app updater after publication, or download the package for your
platform. Existing projects, conversations, and notes remain in place; a clean
installation is not required.
