# v0.1.91 Release Notes

## ai-memory startup hotfix

- On startup, replace an ai-memory sidecar left running by a previous DCC
  session when it serves this installation's data directory. Crashes, force
  quits and update relaunches no longer leave DCC using an older sidecar
  instead of the bundled ai-memory v2.6.1 and its pinned settings.
- Identify an already-running server for another installation or development
  build as shared, and show that state in Settings and the recovered sources
  menu.

## Release scope

- Based on v0.1.90 with only the fix from `1eafe66a`, release version metadata
  and these notes. Pending HTTP and mobile changes are excluded.
- The existing GitHub Actions release workflow builds Linux, macOS Apple
  Silicon and macOS Intel artifacts and leaves the release as a draft.

## Validation

- All 1125 frontend tests passed; desktop TypeScript checks passed.
- All six ai-memory sidecar tests passed, including orphan identification,
  inherited environment isolation and upgrade backups.
- All seven release version references match `0.1.91`.
- The five hotfix files match `1eafe66a` exactly; `git diff --check` passed.
