# v0.1.62 Release Notes

## Conversation message deduplication

- Prevent a submitted user message from appearing twice when the same started
  turn is reconstructed from durable history and replayed by the live event
  stream.
- Normalize absent optional session and turn metadata to explicit `null` values
  so persisted and live event envelopes compare consistently during history
  projection.
- Cover the reconnect and hydration regression with a focused test that
  reproduces the live replay shape.
