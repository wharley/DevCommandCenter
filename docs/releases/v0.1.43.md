# v0.1.43 Release Notes

## Faster, Lighter Code Surfaces

- Replace Monaco with the Pierre editor and diff renderer for more responsive
  cursor movement, selection, file navigation, and line annotations.
- Preserve editable files, split and unified diffs, syntax highlighting,
  changed-line actions, and lazy rendering without retaining Monaco models.
- Restore vertical scrolling for long diffs while keeping Pierre's horizontal
  code overflow behavior intact.

## Better Long-Running Memory Behavior

- Bound frontend session events, queries, terminal history, and inactive editor
  state so completed work can leave the WebView heap.
- Release task and terminal resources when their owning workspace lifecycle
  ends, without changing the normal user flow or discarding unsaved edits.
- Reduce streaming renderer churn and keep live responses fluid during longer
  provider sessions.

## Clearer Agent Activity

- Show native subagent activity in the conversation timeline.
- Reconcile provider message lifecycles more reliably across active and
  completed work.

## Validation Before Publishing

- Run desktop type checks and the complete desktop test suite.
- Build the production desktop client.
- Run Rust formatting and workspace tests.
- Confirm release metadata is `0.1.43` in the root package, sidecar, Cargo, and
  Tauri configuration files.
- Let the release workflow build, sign, notarize, and package Linux and macOS
  artifacts; inspect the draft assets and `latest.json` before publication.
