# v0.3.0 Release Notes

## A native app

- Dev Command Center is now a native app, built in Rust with GPUI, instead
  of a web view inside Tauri. Windows, scrolling and long conversations stay
  smooth. The app uses much less memory and CPU while agents stream, and
  spinners and walking mascots stop drawing while the window is in the
  background.
- Updating from v0.2.0 is the usual click on "Install". Your projects, tasks,
  conversations, accounts and connectors stay where they were.
- From now on the app updates itself: it checks at launch, every 30 minutes
  and when the window gets focus, verifies the signature, and swaps the app
  in place.
- The backend (agents, terminals, the local API) runs inside the app. No
  separate desktop process is needed.

## iOS Simulator for agents

- A Device panel shows a booted simulator next to the conversation, with
  touches, keys, rotation and the hardware buttons. Simulators are listed in
  sections.
- Agents get eleven `dcc_device_*` tools: list, open, screenshot, read the
  accessibility tree, tap by point or by label, swipe, type, buttons, launch
  an app, open a URL and install a build.
- In Expo, React Native and Xcode projects, agents reach for the simulator
  on their own when you ask them to run, test or look at the app. They don't
  boot one just to check their own edits.

## Pull requests

- The pull requests hub lists the PRs of every project, with filters,
  search, checks and merge.
- A PR's code tab says what changed since your review: new commits, the
  author's replies, and the threads whose code changed.
- The file list shows each file's published conversations.
- The Reviewer picks its account, model and effort. A second review follows
  up on your earlier threads instead of starting over.

## Composer and conversation

- Images, files and screenshots copied in Finder or a screenshot tool are
  attached instead of pasted as paths. Pasted images go in at the caret,
  with thumbnails above the field.
- Appshots: a global key, or the composer's + menu, captures another app's
  window into the open task.
- Videos show their first frame and their length. Audio plays with its
  waveform. Images open full size.
- Links show the site's icon and open on Cmd-click. The composer supports
  Markdown lists and emphasis, and `/clear`, `/compact` and `/goal`.
- Select the conversation's text and copy it, copy a code block, and jump
  back to the end of the thread.

## Agents and providers

- The model picker lists what each CLI actually offers your account.
- A card offers newer releases of the agent CLIs (Codex, Claude, Cursor,
  Grok, Gemini) and updates each one the way it was installed.
- Agents run a step below your apps (nice 5), and so do the builds and tests
  they start. When the CPU is busy they give way to the window and the rest
  of the Mac, and when it isn't they use all of it.

## Around the app

- A menu bar item with the agents' activity, and a quick composer on a
  global key.
- System notifications when an agent waits for you.
- The collapsed sidebar shows each task's project mascot, walking while it
  runs.
- A local-direct task's branch under the composer opens the checkout's
  branches to switch or create one.

## Fixes

- Commits, pushes and recoveries wait for the repository's hooks instead of
  timing out after 20 seconds.
- A pull request review waits as long as the Reviewer's turn needs.
- Browser downloads ask where to save once they finish.
- A chip pushed to the next line by the wrap is drawn there, with no blank
  indent.

## Known limits

- The Linux package is built for the first time with the native app. Report
  anything that doesn't work there.
- Windows is not supported yet.
