# v0.2.0 Release Notes

## Connectors in one click

- Settings' Integrations section is now Connectors: search, a Connected
  list, and curated connectors (ClickUp, Linear, Notion, GitHub, Sentry).
  Connect opens the browser, DCC signs in, the window comes back and a toast
  reports how many tools arrived.
- DCC runs the sign-in itself (discovery, PKCE, its own client metadata
  document or a registered client) and keeps the grant in the keychain. The
  agents no longer start their own MCP logins.
- Signed-in connectors reach every provider through DCC's local gateway,
  which refreshes tokens on its own; a lost sign-in shows "sign-in expired ·
  Reconnect" in Settings and above the composer.
- Slack connects with your own app: DCC opens Slack's "create app from
  manifest" already filled in, and you paste the Client ID. A custom server
  that refuses DCC's registration can use your own app or a token. GitHub
  connects with a personal access token.
- Connectors offers once to bring in the remote servers already set up in
  Claude Code, Codex and Cursor.
- Manage tests a connector, lists its tools with Ask/Allow/Deny, and
  switches it off in a single project. A tool with no explicit choice
  follows the task's permission mode, like the provider's own tools.
- A broken or signed-out connector is left out of the turn instead of
  holding it on "Preparing context".

## Goals that run until done (/goal)

- DCC follows the providers' own `/goal` (Claude Code, Codex, Cursor and
  Grok): a strip above the composer shows the goal, its status, checks,
  tokens and the latest reason it is not done yet, with Clear, Continue and
  Close.
- `/goal` and `/compact` typed at the start of a message turn green when the
  selected provider will run them; DCC's own menu actions stay plain.

## PR review comments on the task

- The file badge opens the pull request diff on its first open
  conversation, and a "PR conversations" bar lists every thread, outdated
  and resolved ones included. Reply and resolve from the thread panel.
- Pick several conversations and "Ask agent" puts them in the composer as
  one editable request that quotes each thread.
- Request reviewers from the changes tab, with GitHub's suggestions first;
  pending requests can be withdrawn and past reviewers asked again. GitLab
  sets the merge request's reviewers.
- Long change lists start collapsed, with expand and collapse all.

## Conversation and editor

- `@` file mentions show as file chips (icon, parent folder, name) in the
  composer and the timeline, and open the file in the code column.
- An attached audio file plays in place like a voice note, with its
  waveform and seeking; WhatsApp voice notes included.
- Images open in the file tab as a picture: fit, zoom with buttons, pinch or
  Cmd+scroll, double-click for 100% and drag to pan.
- The editor's tab strip scrolls with arrows and faded edges.
- Each conversation shows the provider it runs on, in the sidebar and in
  the chat history.

## Fixes

- A prompt never lands in another task's session when a task finishes
  starting after you moved to another one.
- A steer no longer repeats the running turn's prompt at the bottom.
- Mobile: the commit message stays above the keyboard in the delivery sheet.
- macOS: stapling the DMG retries when Apple's ticket service drops the
  connection.
