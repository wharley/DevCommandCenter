# v0.1.89 Release Notes

## Conversation performance

- Keep the conversation on screen while a prompt is sent. A runtime restart
  or a full live feed used to blank the timeline until the history was
  reloaded; the shown conversation now stays until the new one lands.
- Show model routing, the model choice and the runtime start below the last
  turn instead of replacing the whole conversation.
- Switch tasks instantly: the last six conversations stay in memory and
  refresh in the background.
- Reopen a conversation where you left it, or at the end if you were
  following it, without animating the scroll or fading every message in.
- Virtualize the conversation: only the messages near the view are mounted.
  On a 140-message conversation a switch renders in ~33 ms instead of
  ~190 ms, with ~9 messages in the page instead of 80.
- Keep folds you opened when you scroll away and back.
- Long conversations no longer re-process their whole history on every live
  update: on a 42,000-event conversation an update costs ~6 ms instead of
  ~37 ms, and opening it ~30 ms instead of ~110 ms.
- Show up to 400 messages before "Load earlier".
- Fix scrolling up being pulled back to the end while older messages load.

## Composer

- Pick the model from one panel: a favorites tab and one tab per provider,
  search across providers, Cmd/Ctrl+1-9 on the visible rows, a star that
  saves a model with its effort, and an effort slider ending in Ultrathink.
- Hide providers switched off in Settings from the composer, code review
  and agent pickers.
- The picker's + opens Settings on Providers.
- List Codex reset credits one per row with their own expiry, soonest first.
- Add Claude Haiku 5.5 as the "haiku" alias; Haiku 4.5 stays for Claude Code
  older than 2.1.293.

## Validation

- 1124 frontend tests passed.

- The virtualized timeline was checked in headless Chromium on real
