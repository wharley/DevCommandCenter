# v0.1.45 Release Notes

## End-to-end Git Delivery

- Add context-aware delivery actions to the Composer dock for checkpointing,
  pushing, syncing the base branch, opening a pull/merge request, and merging.
- Add focused dialogs for creating change requests, syncing the base branch,
  and confirming merges, including draft pull/merge requests.
- Keep delivery actions synchronized with Inspector Git state and prevent
  concurrent operations while a workspace action is running.

## Clearer Forge and Workspace Status

- Support draft change-request status and provider-specific pull/merge request
  details in the Inspector and Composer.
- Improve GitHub and GitLab delivery command handling, conflict reporting, and
  generated frontend bindings.
- Preserve workspace identity and improve the project and session context shown
  around delivery actions.

## Validation Before Publishing

- Run desktop type checks and the complete desktop test suite.
- Run Rust formatting and the relevant Tauri workspace tests.
- Confirm release metadata is `0.1.45` in the root package, sidecar, Cargo, and
  Tauri configuration files.
- Let the release workflow build, sign, notarize, and package Linux and macOS
  artifacts; inspect the draft assets and `latest.json` before publication.
