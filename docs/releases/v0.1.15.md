# v0.1.15 Release Notes

## Highlights

- Added the delegation agents workflow for creating child sessions that can
  review, explain, or implement work in isolated worktrees.
- Added Inspector review support for delegation outputs, including changed-file
  trees, real diffs, apply/discard actions, and routing reviewer feedback back
  to the child agent.
- Hardened delegation cleanup so applied, discarded, and deleted workspace flows
  do not leave child worktrees or stale review state behind.

## Delegation

- Added provider capability metadata and UI controls for launching delegation
  tasks from parent sessions.
- Added session events, persistence, and Activity rendering for delegation
  request, running, review, completed, failed, and cancelled states.
- Added dedicated review affordances in the Inspector so parent sessions can
  inspect child worktree changes before applying them.
- Ensured Apply carries tracked, staged, unstaged, and new untracked files such
  as migrations from the child worktree back into the parent worktree.
- Routed diff feedback sent from a delegation review to the child session so the
  agent keeps the correct context.
- Cleaned up delegation worktrees when applying, discarding, or deleting a
  workspace.

## Validation Before Publishing

- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.15` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
