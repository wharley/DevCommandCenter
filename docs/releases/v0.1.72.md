# v0.1.72 Release Notes

## Chat input

- Prevent a note's prefilled text from reappearing in the chat input after
  sending, including while the first session is being created.

## New files in conversation diffs

- Capture text previews and line counts for files created during an agent
  turn, including files not yet added to Git. Show them as **Added** in the
  conversation timeline.
- Preserve the captured diff so later edits do not change the historical
  preview. Support empty files, CRLF, and files without a final newline.
- Keep files visible when a preview is unavailable, without presenting unknown
  line counts as zero or incomplete counts as the full turn total.
- Support review capture in repositories that do not yet have tracked files.
- Bound preview size and avoid following repository symlinks when reading new
  files. Binary files remain listed without a text preview.

## Validation

- All 789 desktop tests passed, including chat input and timeline regression
  coverage.
- All 9 turn review capture tests passed, including applying captured patches
  with Git and checking that the real Git index remains unchanged.
- Desktop TypeScript checking, the production desktop build, and workspace-wide
  `cargo check --locked` passed.

## Updating

Use the in-app updater after publication, or download the package for your
platform. The new text capture applies to future turns; older reviews without
captured content keep their file list without misleading zero counts.
