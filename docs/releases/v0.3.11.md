# v0.3.11 Release Notes

## The DCC with no screen

- `dcc serve` runs the whole backend with no app open, on a Linux server or
  a Mac nobody sits at: projects, connectors, the agents' tools, and turns
  cut short picked up again. It stops cleanly on Ctrl-C or SIGTERM, and
  refuses to start where the app or another `dcc serve` already runs.
- What the agents react to runs in the server now, with or without the app:
  routines and sources, a failing check on a task's pull request ("CI
  falhou"), review comments on your own pull requests ("Review recebido",
  "Corrigir na tarefa"), and the search of the pull requests you reviewed,
  every 5 minutes.
- A source whose connector broke is no longer read again every minute all
  day: it waits its interval, then longer after each failure, up to six
  hours.
- On a machine with no system keychain (a Linux server), sign-ins are kept
  in a file only your user can read.

## Agents

- When a task an agent opened is merged, the reply goes back to where the
  request came from (Slack, a task). It never fired before.

## Around the app

- A terminal outside tasks: Cmd+Option+T, or the button in the sidebar's top
  bar, opens a window in the corner, in your home folder, with tabs of its
  own. It belongs to no task and no project.
- Account usage shows what a plan has beyond its windows: Codex's credits
  left, and Claude's extra usage this month.
- GitHub people show their picture instead of initials in Pull Requests and
  in a task's review.
- In a running turn, answered approvals and questions sit above the live
  "Escrevendo" line instead of below it.

## Under the hood

- ai-memory is pinned to v3.4.7. Your memory store is migrated once, and
  backed up first to `backups/before-ai-memory-3.4.7/`.
- For apps built on the DCC engine: `DCC_HTTP_CONFIG_PATH` picks the HTTP
  config file, `DCC_HIDE_TOOLS` keeps some of the DCC's own tools out, a
  local tool server can ask which session calls it, a client can list or run
  a connector's tools, and edit-from-here and usage history by day are on
  the HTTP API.
