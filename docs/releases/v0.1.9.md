# v0.1.9 Release Notes

## Highlights

- Refactored the mobile home experience around agent state: needs attention,
  running, and recent work are now distinct sections.
- Added inline permission handling on mobile so blocked agents can be allowed or
  denied without opening the full desktop app.
- Added worktree diff visibility to mobile, including insertion/deletion pills
  and a file-level diff summary screen.
- Improved mobile thread rendering with clearer headers, workspace context,
  live running state, better long-text wrapping, and an auto-growing composer.
- Updated the mobile new-thread flow to group active worktrees by project and
  avoid archived worktrees.

## Data And Runtime

- Mobile comb/workspace data now reads from live `dcc_workspaces` records instead
  of the legacy `combs` table.
- Mobile session listing now joins live sessions to active workspaces, avoiding
  stale orphaned rows from the search index.
- Diff bundle requests can resolve worktree IDs through the live workspace table
  before delegating to the existing git diff logic.

## Documentation

- Added public documentation for running and pairing the mobile web companion
  locally, through Vite HMR, and through Tailscale.

## Validation Before Publishing

- Build the mobile web app: `yarn workspace @dcc/mobile-web build`
- Build the desktop frontend: `yarn build:desktop`
- Check Rust: `cargo check`
- Confirm release metadata is `0.1.9` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
