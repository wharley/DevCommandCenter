# v0.1.57 Release Notes

## Direct pull request merges

- Merge pull requests directly from the pull requests hub without leaving Dev
  Command Center.
- Choose between merge commit, squash, and rebase according to the methods
  allowed by the repository.
- Confirm the selected method before merging and refresh pull request details
  automatically after completion.
- Prevent unsafe merges when the pull request is a draft, has conflicts, the
  viewer lacks permission, or the head commit changed unexpectedly.
- Show localized success and error feedback in English and Brazilian
  Portuguese.

## Open existing project branches

- Open an existing local branch directly from a project's workspace actions.
- List available branches in the workspace dialog and use the selected branch
  when creating the workspace.
- Keep the existing new-workspace flow available while making branch-based
  workspaces easier to discover from the sidebar.
- Localize the new branch selection and workspace actions in English and
  Brazilian Portuguese.

## Validation before publishing

- Pass the complete desktop test suite with 477 tests, desktop type checks, and
  the production frontend build.
- Pass Rust compilation for the Tauri application and workspace crates.
- Confirm the release diff has no whitespace errors.
- Confirm release metadata is `0.1.57` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create the
  GitHub draft release for final publication.
