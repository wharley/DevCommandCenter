# v0.1.20 Release Notes

## Highlights

- Modernized the Composer, Terminal, and Inspector around a calmer mission
  cockpit: the primary action stays obvious while advanced controls and runtime
  detail remain available through progressive disclosure.
- Reworked the Terminal into a resizable bottom drawer so it no longer competes
  horizontally with the conversation and Inspector.
- Improved keyboard navigation, focus behavior, responsive hierarchy, density
  controls, localization, and local-only UX instrumentation across the desktop
  workbench.

## Composer

- Reduced the default toolbar to provider/model, Add context, Plan mode, one
  execution-profile control, and the primary Send/Steer/Stop action.
- Consolidated response speed, reasoning effort, and session usage into the
  execution menu without removing expert controls.
- Hid the permanent context row when it only contains implicit workspace
  context, while keeping additional directories visible and removable.
- Moved Terminal access out of the Composer and into the workbench header.
- Added container-aware responsive labels so secondary controls collapse before
  the main prompt action is compressed.
- Localized new and updated Composer copy and accessible labels in English and
  Brazilian Portuguese.

## Terminal

- Replaced the right-side Terminal split with a vertically resizable bottom
  drawer and retained full-workbench expansion.
- Preserved a usable conversation height when space allows, with compact-window
  minimums and persisted drawer height.
- Simplified the default chrome to one scope selector, semantic terminal tabs,
  and window controls; runtime identifiers, CWD, linked-session details, and
  maintenance actions now live behind details or tab menus.
- Added project/worktree scope switching directly in the drawer, plus clearer
  tab status indicators.
- Added arrow, Home, and End navigation for terminal tabs, moved focus into the
  Terminal when opened, and restored Composer focus when closed.
- Fixed terminal fitting and overflow so the xterm viewport uses the actual
  visible drawer height instead of extending beyond the app boundary.

## Inspector and Activity

- Made the Inspector collapsed by default while preserving the user's explicit
  visibility preference.
- Moved Changes / Files navigation to the top and placed the workspace recap
  immediately below it.
- Established one owner for Git workflow actions: Changes performs mutations,
  while Files uses the recap to navigate to Changes. Post-merge Continue remains
  reachable without duplicating calls to action.
- Kept the session dock calm by default and limited automatic opening to a fresh
  plan that needs attention.
- Hid empty secondary Inspector surfaces and moved account connections and
  verbose runtime context into collapsible detail sections.
- Replaced the noisy default event stream with localized semantic milestones;
  raw event names and payloads remain available in Diagnostics.
- Clarified context-usage reporting so provider data is preferred and estimates
  are identified as estimates.
- Fixed recap ownership, localized the remaining Continue action, and added
  regression coverage for the updated recap decisions.

## Interaction Quality and Preferences

- Added comfortable and compact density preferences, clearer elevation levels,
  fewer nested borders, and more readable daily-use metadata.
- Expanded command-palette coverage for Composer, Terminal, and Inspector
  actions.
- Added global shortcuts for the command palette, Composer focus, Terminal, and
  Inspector Changes / Files, and surfaced them in Settings and the shortcut
  cheatsheet.
- Kept Inspector secondary navigation scrollable at narrow widths.
- Added aggregate local-only UX metrics for feature discovery and control use;
  metrics exclude prompt content, paths, and session identifiers and can be
  inspected or reset in Settings.

## Editor and Annotation Polish

- Fixed the Send to agent annotation dialog so its instruction field receives
  focus after positioning, keeps modal focus from returning to Monaco, and can
  be typed into immediately.
- Replaced generic editor glyphs in the workspace header with recognizable
  Cursor, Zed, VS Code, VS Code Insiders, and Trae brand marks.
- Centralized the Cursor mark so editor and provider surfaces stay consistent.

## Validation Before Publishing

- Run desktop type checks: `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite: `yarn workspace @dcc/desktop test`
- Build the production desktop frontend: `yarn workspace @dcc/desktop build`
- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.20` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
