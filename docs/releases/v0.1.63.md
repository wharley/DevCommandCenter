# v0.1.63 Release Notes

## Reliable delivery-failure handoff

- Preserve captured delivery-failure context until the Composer confirms that
  the text was actually written, instead of acknowledging the request early.
- Keep composer injection identifiers monotonic after consumption so repeated
  **Send to agent** actions are not discarded as duplicates.
- Isolate request identities across delivery recovery, diff annotations,
  conversation recovery, and session changes while retaining the intended
  append or replace behavior for each flow.
- Apply prefilled context inside the Lexical editor lifecycle so Composer and
  session remounts cannot lose an otherwise successful handoff.
- Cover the identifier-collision regression with a focused test.

## Validation before publishing

- Pass the complete desktop test suite with 689 tests, desktop type checks, and
  the production frontend build.
- Pass Rust workspace tests, the sidecar test suite, the local MCP release gate,
  and Rust formatting checks.
- Confirm the release diff has no whitespace errors.
- Confirm release metadata is `0.1.63` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create
  the GitHub draft release for final verification and publication.
