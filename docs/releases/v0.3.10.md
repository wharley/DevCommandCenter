# v0.3.10 Release Notes

## Agents that close the loop by themselves

Everything here is off until you turn it on, per agent, under "Enviar sem
perguntar" on the agent's page. The merge is never automatic.

- "Revisão de pull request": the Reviewer's review goes by itself in the
  projects you pick — "Só comentar" publishes its comments, "Comentar e
  decidir" also approves or requests changes. A review it could not decide
  goes as a comment. When one that should have gone did not, its card in the
  room says why ("não enviado: …").
- "Resposta para fora": the reply an agent proposes (in Slack, on a task)
  goes without you pressing "Enviar", in the rooms you pick, up to 20 a day.
- "Entrega da tarefa": a task an agent opened is committed, pushed and gets
  its pull request when it ends a turn with changes, in the projects you
  pick. Only a task in its own worktree; a refusal (a check before the push,
  a branch behind) is told and waits for you.
- "Ao abrir o PR": what the agent should do when that pull request opens, in
  your words ("avise no #tech marcando o Giovanni"). The agent announces it
  through its connectors, so it works for Slack, ClickUp, Jira.
- "Comentários no seu PR" › "Corrigir na tarefa": what reviewers wrote on
  your own pull request, on a line or in its conversation, goes straight to
  the task's agent to fix, instead of a second agent only reading it.
- Work asked on a pull request or a branch that already has a task goes to
  that task; no second task is opened for it.
- "Conferir", at the foot of the card, says what you set that will not work
  as you expect: a grant with no project or room, replies granted in a room
  the agent's sources do not use, a choice whose trigger is off.
- A review cut short by quitting the app starts again when it opens.

## The right project

- The room says which project a request is for. A source brings its news to
  a room ("Avisar na sala"); in a project's room the task an agent opens
  goes to that project. Geral has no project.
- A task opened by an event (a source, a trigger, a routine, a teammate's
  pass) starts by itself only in the room's project or in a project chosen
  for the agent under "Projetos". Anywhere else it waits as a card. A task
  you ask for yourself starts as before.
- An agent now sees each project's repository and folder, not only its
  name, and is told that a name matching a word of the request is not the
  project.
- If you have a source in Geral that brings requests about one project,
  move it to that project's room ("Editar" on the source).

## The Guide

- A new built-in agent, "Guia", joins the team when the app opens. Call it
  with @Guia. You can rename it, change its mascot and pick its model; one
  you delete is not made again.
- It reads how the team is set up before answering whether it is right or
  why something did not happen, and reads the help before explaining a
  screen, naming the buttons as the app shows them.
- It proposes instead of listing steps: a new agent, a source, a routine,
  and a change to what exists — a source's room, interval or switch, the
  projects an agent works in — as a card with the before and the after,
  "Aplicar" and "Descartar", and "Aplicar todos" when several wait.
- When you ask, it proposes what an agent does without asking as a card of
  its own, with a warning and a "Liberar" button. Only your click turns it
  on; no agent does, and such a card is never part of "Aplicar todos".
- It opens no task, changes no code and sends nothing outside.
- The help ("?") has three new topics: "Salas dos agentes", "Fontes e
  rotinas" and "Enviar sem perguntar".

## Sources

- A source can read every 1 or 2 minutes, besides 5, 15, 30 and 60.
- A connector that answers with one document for several items (a search
  that returns text) is read item by item, so one new message is news and
  the old ones are not told again.
- An agent that finds a question it cannot answer from where it is passes it
  to a teammate that can, and a reply says only what was checked.

## Around the app

- The task's header shows the team as a pile of mascots that opens a list
  with each agent's name and, while it cannot be called, why.
- Pull Requests › Resumo › "Revisão" has "Pedir revisão": a search over who
  can review, suggested people first, each with their picture.
- Two more mascots for an agent: a cat and a cloud.
