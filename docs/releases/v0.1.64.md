# v0.1.64 Release Notes

## GPT-6 Astra

- Add GPT-6 Astra to the Codex model catalog and make it the recommended model
  for new selections.
- Keep GPT-5.6 Sol, Terra, and Luna available with their existing model IDs and
  aliases.
- Add the convenient `astra` and `6-astra` aliases for the canonical
  `gpt-6-astra` model ID.
- Expose Astra's supported low, medium, high, extra-high, and max reasoning
  levels in the model picker.
- Preserve Astra's max reasoning effort when sending turns through the Codex
  app-server while retaining the existing behavior for earlier models.

## Validation before publishing

- Pass the complete desktop test suite, desktop type checks, and the production
  frontend build.
- Pass Rust workspace tests, the sidecar test suite, the local MCP release gate,
  and Rust formatting checks.
- Confirm the release diff has no whitespace errors.
- Confirm release metadata is `0.1.64` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create
  the GitHub draft release for final verification and publication.
