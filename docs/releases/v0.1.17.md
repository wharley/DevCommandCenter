# v0.1.17 Release Notes

## Highlights

- Added GPT-5.6 Sol, Terra, and Luna to the Codex provider catalog, including
  canonical model IDs and convenient aliases.
- Added Grok Build as a stable provider through its native Agent Client Protocol
  (ACP) CLI integration, without a direct API integration.

## Grok Build

- Added the `grok-4.5` model with low, medium, and high reasoning effort.
- Added ACP session startup, local CLI authentication, streaming text, reasoning,
  and tool lifecycle event handling.
- Added support for `GROK_HOME` provider runtime configuration and Grok Build in
  desktop fallback and mobile new-session catalogs.
- Added a dedicated Grok Build icon across desktop and mobile provider selectors.

## GPT-5.6

- Added `gpt-5.6-sol`, `gpt-5.6-terra`, and `gpt-5.6-luna` to Codex.
- Added aliases for the GPT-5.6 family and model catalog coverage.

## Validation Before Publishing

- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Run provider and core tests: `cargo test -p dcc-providers` and
  `cargo test -p dcc-core`
- Confirm release metadata is `0.1.17` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
