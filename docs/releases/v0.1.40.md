# v0.1.40 Release Notes

## Model-aware Delegation

- Delegate directly from the composer while keeping the recommended model as
  the fast, one-click path for each provider.
- Open a provider's model catalog from the same compact menu when a specific
  model should receive the work.
- Preserve fan-out delegation with each provider resolving its own recommended
  model.

## Plan Handoff

- Approved plans now use the same provider and model picker as composer
  delegation.
- Remove the hidden fixed-model preference from plan implementation, so the
  selected target is always explicit.
- Keep implementation delegation isolated in its protected worktree and under
  the existing review-before-apply workflow.

## Delegation Traceability

- Persist the exact target model with every new delegation.
- Show both provider and model on delegation cards, making agent handoffs easier
  to understand and compare.
- Keep existing delegation records compatible when they predate model tracking.

## Validation Before Publishing

- Run desktop type checks:
  `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite:
  `yarn workspace @dcc/desktop test`
- Run the Tauri library test suite:
  `cargo test -p dcc-tauri --lib`
- Run the delegation persistence test:
  `cargo test -p dcc-infra sqlite_session_repo_persists_delegations_and_status_updates`
- Check Rust formatting:
  `cargo fmt --all -- --check`
- Confirm release metadata is `0.1.40` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
- Let the release workflow build, sign, and package Linux and macOS artifacts;
  review every draft asset and `latest.json` before publishing.
