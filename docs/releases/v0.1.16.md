# v0.1.16 Release Notes

## Highlights

- Added a direct delegation action to plan follow-up flows so users can start
  implementation work from an approved plan with less context switching.
- Added a dedicated development Tauri config for local iteration.
- Fixed a Git fetch/display failure path so workspace Git state can recover
  cleanly instead of breaking the app surface.

## Fixes and Improvements

- Added a delegation button to plan follow-up content and composer surfaces.
- Updated delegation dialog handling so plan-driven delegation can carry the
  expected task context into the child session.
- Added coverage for plan follow-up content and Git error handling behavior.
- Added `src-tauri/tauri.dev.conf.json` usage to the local `dev:tauri` flow.
- Improved fallback rendering around Git/Inspector failures to avoid blocking
  the main workspace UI.

## Validation Before Publishing

- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.16` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
