# v0.1.34 Release Notes

## Highlights

- Diff viewers keep a stable side-by-side layout in narrow windows, so the
  original file no longer disappears when Monaco switches to its inline mode.
- Merge conflict resolution now offers an explicit **Complete merge** checkpoint
  once every conflict is clear of markers, instead of leaving the workspace stuck
  on **Resolve conflicts**.
- Agents asked to recover delivery failures are instructed to leave staging,
  commit, and push to the Inspector completion flow.

## Diff Viewer Layout

- Monaco diff editors disable `useInlineViewWhenSpaceIsLimited`, so a narrow DCC
  window keeps the before/after columns instead of collapsing below 900px.
- Workspace editor and Inspector git file preview hosts use `min-w-0` so flex
  layout can constrain the Monaco surface without horizontal overflow.

## Merge Conflict Completion

- Introduced a `complete-merge` commit mode that appears when a merge is in
  progress and either no conflicts remain or every text conflict is marker-free
  and ready to stage.
- The Inspector git header surfaces a review-resolution action alongside the
  emerald completion control, with confirmation copy for staging, validation,
  merge commit, and push.
- Recap messaging distinguishes unresolved conflicts from resolutions that are
  ready to complete, in English and Brazilian Portuguese.
- Delivery-failure recovery prompts tell agents to resolve text conflicts and
  run validations, but not to stage, commit, or push — that checkpoint stays in
  the Inspector.

## Validation Before Publishing

- Run desktop type checks: `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite: `yarn workspace @dcc/desktop test`
- Build the desktop application: `yarn workspace @dcc/desktop build`
- Build the mobile web application: `yarn workspace @dcc/mobile-web build`
- Run the Rust workspace tests: `cargo test --workspace`
- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.34` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
