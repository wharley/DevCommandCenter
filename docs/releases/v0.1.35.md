# v0.1.35 Release Notes

## Highlights

- Workspace organization now separates paused work into **Waiting** and finished
  work into **Completed**, keeping the active project list focused.
- Completed workspaces can clean up their remote branches during deletion, with
  safeguards for base, default, and protected branch names.
- Project removal now handles repositories with nested worktrees and refreshes
  the sidebar immediately after local state is cleared.
- The expanded workspace sidebar scrolls correctly when the window is not
  maximized or the workspace list exceeds the available height.

## Workspace Lifecycle

- Active workspace cards offer visually distinct actions to complete work or put
  it on hold, with clear tooltips and status-specific colors.
- Waiting workspaces expose only the restore action, while completed workspaces
  expose only deletion.
- Regular workspaces move to Completed automatically after their pull request is
  detected as merged.
- Existing archived workspaces and sidebar preferences migrate to the Waiting
  section without losing their stored state.
- Workspace cards show initialization, pending setup, and ready-to-start states
  before agent activity and recap details.

## Cleanup and Navigation

- Deleting a completed workspace can also delete its remote branch when the user
  keeps the confirmation option selected.
- Remote deletion resolves the configured remote and branch, verifies that the
  branch exists, and refuses unsafe targets such as `main`, `master`, `trunk`,
  the workspace base branch, or the remote default branch.
- Removing a project clears associated workspace state, supports nested Git
  worktrees, and refreshes both repositories and workspaces.
- The virtualized expanded sidebar now owns a vertical scroll viewport with a
  compact scrollbar, matching the already-scrollable collapsed rail.

## Validation Before Publishing

- Run desktop type checks: `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite: `yarn workspace @dcc/desktop test`
- Build the desktop application: `yarn workspace @dcc/desktop build`
- Build the mobile web application: `yarn workspace @dcc/mobile-web build`
- Run the Rust workspace tests: `cargo test --workspace`
- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.35` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
