# v0.1.41 Release Notes

## Provider-aware Conversation Timeline

- Preserve native assistant-message identity and lifecycle signals instead of
  reducing every provider to an undifferentiated text stream.
- Reconcile streamed deltas with authoritative completion snapshots, recovering
  cleanly from missing, duplicated, or partially delivered chunks.
- Keep reasoning, tools, permissions, intermediate commentary, and final
  answers in a stable semantic order throughout a turn.
- Prefer an explicitly identified final answer when the provider publishes one;
  otherwise select the last complete assistant message without discarding the
  earlier context.

## Cross-provider Fidelity and Recovery

- Improve timeline translation for Codex, Claude, Gemini, Cursor, Droid, and
  Grok while retaining safe fallbacks for runtimes with fewer lifecycle signals.
- Preserve Claude root-message boundaries and final snapshots without
  flattening subagent text into the main conversation.
- Carry message identity, phase, and completion data through persistence so a
  reopened conversation reconstructs the same timeline.
- Apply the same completion-aware projection to desktop and mobile conversation
  history.

## Clearer Planning Control

- Explain Plan mode with a concise tooltip whether the responsive composer
  shows only its icon or the icon and label.
- Reflect the active state through contextual tooltip text and accessible
  pressed-state semantics.

## Validation Before Publishing

- Run desktop type checks:
  `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite:
  `yarn workspace @dcc/desktop test`
- Build the desktop and mobile clients:
  `yarn workspace @dcc/desktop build` and
  `yarn workspace @dcc/mobile-web build`
- Run the Claude sidecar test suite:
  `yarn --cwd sidecar test`
- Run core, provider, infrastructure, and Tauri library tests:
  `cargo test -p dcc-core`, `cargo test -p dcc-providers`,
  `cargo test -p dcc-infra`, and `cargo test -p dcc-tauri --lib`
- Check Rust formatting:
  `cargo fmt --all -- --check`
- Confirm release metadata is `0.1.41` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
- Let the release workflow build, sign, and package Linux and macOS artifacts;
  review every draft asset and `latest.json` before publishing.
