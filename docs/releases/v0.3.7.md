# v0.3.7 Release Notes

## Remote machines (first version)

Run a task on another computer's DCC and work on it from yours. The other
computer runs the agents, git and its own provider accounts; yours shows the
task as a local one. Both sides need this version, and the machine's DCC has
to be open. This is the first version: it was built against the relay and
covered by tests, and is being tried between two computers with this release.

- "Conexões" in Settings has two tabs: "Quem acessa este computador" (the
  relay, the paired devices and the audit log) and "Máquinas que eu acesso",
  where a `dcc://pair` link made by the other machine's DCC pairs it. The
  person on the machine approves, comparing this computer's code, shown
  there. A DCC never pairs with itself.
- "Onde" in Nova tarefa: with a machine paired, pick "Este computador" or a
  machine by name. Picking a machine lists that machine's projects and the
  task is created there.
- The task shows in the list as "… · em outra máquina" and its conversation
  works as usual: prompts, stop, queue, approvals and questions go to the
  machine. Your provider account is never sent along: the machine runs agents
  on its own accounts.
- "Mudanças" lists what the task changed on the machine (not committed yet,
  and on its branch); a click opens the diff on the stage.
- The delivery rail (Commit → Enviado → PR → Checks → Revisão → Merge) shows
  for a remote task too, and its next step runs on the machine, with its git
  and its forge login, after you confirm what it will do there.
- "Arquivos" shows the machine's file tree; a file opens on the stage to
  read.
- The terminal of a remote task is a shell on the machine, in the task's
  folder there. A paired device reaches only the terminals it opened.

Known limits: a remote file is read-only and capped at 500 KB (images and
binaries do not open); Quick Open and the search do not read the machine; the
commit message and the pull request title are the machine's own; rename, pin,
archive and delete act on this computer's copy only.
