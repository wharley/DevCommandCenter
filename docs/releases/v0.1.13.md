# v0.1.13 Release Notes

## Highlights

- Fixed realtime mobile thread updates by accepting both persisted session
  events and live core SSE events.
- Refined the mobile thread UX so active work, tool activity, permissions, and
  assistant output are easier to follow on a phone.
- Added live workspace context to the mobile thread header, including running
  state and diff counters when the session changes files.

## Mobile Thread

- Normalized incoming `session*` core events into the same timeline model used
  by stored session events, covering turn start/delta/completion, reasoning,
  tool calls, permission requests, aborts, and session lifecycle events.
- Filtered the global SSE stream by session ID before applying updates, so each
  mobile thread only renders events from its own session.
- Added optimistic local turn insertion after sending a prompt, keeping the
  conversation responsive while the realtime stream catches up.
- Grouped reasoning, completed permissions, and tool-call lifecycle rows into a
  collapsible activity block so the thread reads as user message, activity,
  assistant response.
- Kept unresolved permission requests as standalone action cards for fast
  approval/denial from mobile.
- Added a sticky thread top bar with live/idle state, workspace/branch metadata,
  and a diff shortcut showing current insertions/deletions for the related
  workspace.

## Validation Before Publishing

- Typecheck the mobile web app: `yarn workspace @dcc/mobile-web typecheck`
- Build the mobile web app: `yarn workspace @dcc/mobile-web build`
- Confirm release metadata is `0.1.13` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
