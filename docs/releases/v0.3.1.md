# v0.3.1 Release Notes

## Pull requests you reviewed

- "Pull Requests" in the sidebar shows how many pull requests you reviewed
  got new commits or replies from their author since your review. The
  collapsed sidebar shows a dot.
- In the hub they come first, tagged with what came ("2 new commits ·
  @author replied on the PR"). Opening one marks it as seen, and it stays
  where it is in the list until the hub opens again.
- Each pull request you reviewed says how you reviewed it: approved,
  requested changes or commented.
- A system notification tells you about new activity once, only while you
  are in another app.
- The tabs now read Reviewing, Created by you, All, and the hub opens on
  Reviewing.
- One GitHub search every 5 minutes covers every repository, so the check
  stays light however many projects you have.

## Commit and pull request text

- A ✨ beside the commit's subject and body, and beside the pull request's
  title and description, writes that one field with the task's own agent
  (its provider, account and model). It runs only when you click it, outside
  the conversation, and you edit the result before anything is sent. Click it
  again to stop.

## Fixes

- A long review in a pull request's code tab scrolls inside its field, so
  the send button no longer leaves the window.
- Updating Claude Code, Codex or Gemini installed with Homebrew uses the
  package you installed (for example `claude-code@latest`), and a CLI that npm
  installed with Homebrew's Node updates with that npm.
- After an update, the background service restarts on the new version
  instead of keeping the previous one running.
