# v0.1.93 Release Notes

## Keep the Mac awake

- Settings → General → "Manter o Mac acordado": Off (default), Always (while
  DCC is open) or While agents work. While agents work holds a macOS
  idle-sleep assertion during active turns (including turns waiting for an
  approval) and for two minutes after the last one, so a queued turn can start.
- A ☕ in the menu bar shows when and why the Mac is being kept awake.
- With the lid closed macOS still sleeps unless the Mac is in closed-display
  mode (power, external display, keyboard and mouse); the help explains this.

## Phone companion

- Browser and computer-use requests from agents reach the phone: one registry
  for the desktop dialog, the native panel and the phone, first answer wins.
  Computer use from the phone warns that nobody is in front of the Mac and asks
  for confirmation. Sign-in, MFA, CAPTCHA and payment steps still need the Mac.
- "Needs you" on the phone covers every desktop reason: conflicts, PR
  conflicts, checks, delegated work to review, woke up, setup, interrupted and
  unseen results. Conflicts and red CI send a push once.
- Delivery from the phone: diff summary, commit with the desktop's
  deterministic message (editable), push, update-and-push, draft or ready PR,
  PR and CI state, finish and archive. Conflicts and merges stay on the Mac.

## Validation

- All 1131 frontend tests passed; desktop TypeScript checks passed.
- Rust workspace tests passed except the three known `dcc-mcp-fixture`
  failures, unrelated to this release.
- The relay end-to-end test passed, including a browser request answered and a
  commit made from the phone.
- Keep-awake verified on a Mac with `pmset -g assertions` during a real agent
  turn.
