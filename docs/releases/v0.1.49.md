# v0.1.49 Release Notes

## A new identity for DCC

- Introduce the DCC orchestrator mark: a strong technology symbol whose four
  continuous flows and eight endpoints subtly suggest multiple agents working
  through one command core.
- Apply the new identity consistently across the macOS Dock, Linux and Windows
  launchers, mobile icons, favicons, and web assets.
- Add the standalone glyph and compact `DCC` signature to the workspace sidebar
  while preserving the existing collapse control and draggable window area.
- Refresh the README with the vector mark and document the concept, usage rules,
  source assets, and platform-icon regeneration workflow.

## Clearer commit preparation

- Open the commit preview immediately with a visible preparation state while DCC
  stages changes and asks the selected provider for a message suggestion.
- Prevent rapid repeated clicks from creating duplicate commit previews or
  overlapping provider requests.
- Keep the preparation dialog safely locked until it finishes and surface a
  localized error when preparation cannot be completed.

## Validation before publishing

- Run desktop type checks, the complete desktop test suite, and the production
  desktop build.
- Run Rust formatting, workspace checks, and the complete Rust test suite.
- Confirm release metadata is `0.1.49` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts, inspect the
  draft release and `latest.json`, then publish only after manual verification.
