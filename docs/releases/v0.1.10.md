# v0.1.10 Release Notes

## Highlights

- Improved the desktop conversation timeline so agent reasoning and tool
  activity stay compact while the final assistant response remains easy to read.
- Added a cleaner activity group for live work, completed work, and failed tool
  calls, with detailed output available on demand.
- Kept Git diffs anchored in the inspector instead of duplicating full diffs in
  chat, while preserving the closing review affordance for edited files.

## Conversation And Runtime

- Separated the live session event buffer used for conversation projection from
  the short activity feed shown in the inspector.
- Preserved more live stream deltas until persisted session history catches up,
  preventing long assistant outputs from being reconstructed from a truncated
  activity feed.
- Strengthened assistant markdown list and spacing styles so bullets and
  paragraphs render consistently during and after streaming.

## Validation Before Publishing

- Typecheck the desktop app: `yarn workspace @dcc/desktop typecheck`
- Build the desktop frontend: `yarn workspace @dcc/desktop build`
- Confirm release metadata is `0.1.10` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
