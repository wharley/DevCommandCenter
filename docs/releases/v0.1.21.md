# v0.1.21 Release Notes

## Highlights

- Simplified Git review discovery by keeping the workbench header indicator as
  the single, authoritative entry point for current workspace changes.
- Removed the redundant per-message edited-files card, whose provider tool-call
  metadata could omit paths and produce inconsistent results.
- Refined the one-time Inspector discovery animation so it appears only when
  real Git changes are waiting for review.

## Git Review Experience

- Preserved the compact header indicator with the current changed-file count,
  additions, deletions, and direct access to the Inspector.
- Removed the closing assistant-message card and its unused localized copy in
  English and Brazilian Portuguese.
- Kept delegation review actions connected to the Inspector while removing the
  obsolete per-turn edit-card plumbing.
- Updated related code documentation to describe review of the current Git
  state instead of attributing changes to an individual assistant turn.

## Inspector Discovery

- Delayed the discovery pulse until the Inspector is collapsed and the real Git
  status reports at least one changed file.
- Prevented a clean workspace from consuming the one-time discovery hint before
  there is anything to review.
- Added an in-memory one-time guard for environments where local storage is not
  available.
- Introduced a fresh discovery key so existing users can see the improved hint
  once after updating.
- Preserved the Inspector's subtle entrance animation when the panel is opened.

## Validation Before Publishing

- Run desktop type checks: `yarn workspace @dcc/desktop typecheck`
- Run the complete desktop test suite: `yarn workspace @dcc/desktop test`
- Build the production desktop frontend: `yarn workspace @dcc/desktop build`
- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.21` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
