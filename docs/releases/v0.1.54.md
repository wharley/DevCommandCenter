# v0.1.54 Release Notes

## Conversation links

- Highlight workspace file references with file or code-file icons so clickable
  paths are immediately distinguishable in the conversation timeline.
- Give external web links a separate visual treatment and icon while preserving
  the existing workspace-aware file opening behavior.
- Recognize local Windows paths written with either slash style and trim link
  targets before opening them.

## Completed workspace storage

- Show the approximate total disk space used by completed worktrees directly
  in the Completed section header.
- Show the approximate space that will be reclaimed in the permanent workspace
  deletion dialog, including a loading state while the size is measured.
- Expand coordinated multi-project workspaces into their member worktrees so
  the aggregate and deletion estimates cover the complete task.

## Performance and safety

- Measure worktree storage on a blocking background worker so directory scans
  do not stall the desktop interface.
- Resolve workspace IDs through DCC before scanning, skip the protected root
  repository, deduplicate paths, and never follow symbolic links.
- Keep disk usage unavailable for remote backends where the local desktop
  process cannot safely represent the remote filesystem.

## Validation before publishing

- Pass the complete desktop test suite with 473 tests, desktop type checks, and
  the production frontend build.
- Pass the focused Rust directory-size test.
- Pass Rust compilation for both the reusable Tauri crate and the desktop
  application, with generated TypeScript contracts refreshed.
- Confirm release metadata is `0.1.54` in the root package, sidecar, Cargo, lock,
  and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create the
  GitHub draft release for final publication.
