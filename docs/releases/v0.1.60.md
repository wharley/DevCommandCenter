# v0.1.60 Release Notes

## Provider context handoff

- Carry a bounded, provider-neutral context packet into the next turn when an
  existing DCC session switches between Claude Code, Codex, Gemini, Cursor, or
  Grok.
- Preserve the active workspace, branch and Git summary, mission context,
  approved plan, and recent completed conversation without claiming a raw
  cross-provider transcript transfer.
- Keep explicit delegation separate: provider switching continues in the same
  task, while delegated implementation still runs in an isolated child
  worktree for review and apply/discard.

## Project skills

- Save the neutral `.devcommandcenter/skills/` source in the active checkout:
  the protected worktree for isolated tasks and the repository checkout for
  local-direct tasks.
- Authorize save, delete, and compile operations with the exact workspace ID so
  multiple tasks sharing a repository root no longer make skill mutations
  ambiguous.
- Keep source and provider projections in the same reviewable commit, preserve
  previously compiled targets when a legacy checkout has no source manifest,
  and show useful native error messages in the Skills dialog.
- Align managed skill cards with the detected-project inventory.

## Composer and startup polish

- Refresh the queued-turn card as soon as its message is dispatched, so the
  composer no longer retains a stale queued entry while the agent continues.
- Localize the startup splash using the saved DCC language and replace its
  placeholder dot with the DCC glyph used in the sidebar.

## Documentation

- Document automatic provider handoff and its honest context boundary.
- Add the incremental Split Chat Workbench proposal, including pane identity,
  routing, Inspector ownership, concurrency safeguards, rollout, and testing.

## Validation before publishing

- Pass the complete desktop test suite with 552 tests, desktop type checks, and
  the production frontend build.
- Pass Rust workspace tests, sidecar tests, and Rust formatting checks.
- Confirm the release diff has no whitespace errors.
- Confirm release metadata is `0.1.60` in the root package, sidecar, Cargo,
  lock, and Tauri configuration files.
- Let the release workflow build signed macOS and Linux artifacts and create
  the GitHub draft release for final verification and publication.
