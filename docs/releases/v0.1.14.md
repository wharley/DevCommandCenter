# v0.1.14 Release Notes

## Highlights

- Fixed the packaged mobile pairing page so QR codes open the bundled mobile web
  app correctly in production builds.
- Kept the mobile HTTP backend behavior unchanged; this release only broadens
  where `dccd-http` looks for bundled mobile assets.

## Mobile Pairing

- Resolved mobile web assets from app resource directories in addition to the
  existing development and side-by-side binary paths.
- Covered the macOS Tauri bundle layout where `mobile-web` is packaged under
  `Contents/Resources/mobile-web`.
- Added Linux-friendly fallback paths such as `resources/mobile-web` without
  changing the release build order.

## Validation Before Publishing

- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.14` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
