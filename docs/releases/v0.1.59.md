# v0.1.59 Release Notes

## Composer submission

- Clear the chat composer immediately after pressing Enter so the submitted
  prompt no longer remains visible while the request is being accepted.
- Restore the draft when submission is rejected or fails, without overwriting
  newer content or content from another workspace.
- Prevent duplicate sends and delegation submissions while a submission is in
  flight.
- Configure desktop tests with `jsdom` so browser-dependent modules run in the
  same environment as the application.

## Validation before publishing

- Pass the complete desktop test suite with 542 tests.
- Pass desktop type checks and the production frontend build.
- Confirm the release metadata is `0.1.59` across package, sidecar, Cargo, lock,
  and Tauri configuration files.
