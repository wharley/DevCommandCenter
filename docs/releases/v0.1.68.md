# v0.1.68 Release Notes

## Persistent project notes

- Capture ideas from the composer or an assistant reply without interrupting the
  current task. Notes preserve their own text and source context.
- Move, minimize, color, and pin floating notes; browse and filter them in the
  sidebar library. Open notes return when you revisit their associated task.
- Turn a note into a task or add its context to a conversation as a reviewable
  draft. Complete notes when their work is finished.
- Notes are stored separately from task history and worktrees. Deleting a source
  task preserves the note and its saved context.

## A consistent desktop interface

- Refine the project sidebar, task launch screen, composer context previews,
  settings, and assistant activity with clearer hierarchy and shared surfaces.
- Improve the diff inspector and Pull Requests views, including comparison scopes,
  branch context, file navigation, and inline review drafts.
- Bring code-selection actions and annotation composers into the same design in
  diffs, editable files, and pull request reviews.
- Refresh the objective panel with visible status, counters, grouped execution
  limits, and persistent actions.
- Refresh opening and cloning projects with grouped fields, a fixed action footer,
  and more readable paths and branch names.
- Support compact windows, light and dark themes, visible keyboard focus, and
  reduced-motion preferences throughout the updated surfaces.

## Skills library and DCC catalog

- Separate project skills, detected agent context, and the bundled DCC catalog.
- Search project skills and review agent destinations in a more spacious editor.
- Add the orchestration template from the catalog after reviewing its instructions
  and target agents. Project copies are editable without changing the template.
- Show which catalog templates are already present in the project.

## Validation

- 710 desktop tests and 43 sidecar tests passed.
- Six focused Rust tests passed for note persistence, concurrency, history cleanup,
  and bounded attachment previews.
- Desktop TypeScript checking, the production frontend build, and workspace-wide
  `cargo check` passed.
- Browser fixtures exercised the updated surfaces in light/dark themes and compact
  layouts, including note restoration, code annotations, the skills catalog,
  objective controls, and opening/cloning projects.
- Signed release artifacts remain subject to CI verification and installed-app
  validation before publication.

## Updating

Use the in-app updater after publication, or download the package for your platform.
Existing projects and conversations remain in place. The notes library is added to
DCC's existing local database; a clean installation is not required.
