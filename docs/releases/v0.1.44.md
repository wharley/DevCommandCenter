# v0.1.44 Release Notes

## Clearer Native Subagent Activity

- Preserve native subagent identity when start and completion events use
  different event identifiers for the same child thread.
- Show native subagents as dedicated timeline cards with their name, role,
  model, and current status instead of hiding them inside the generic activity
  disclosure.
- Keep activity summaries focused on tool calls and reasoning while retaining
  the full subagent result in the conversation.

## Git Status That Matches the Inspector

- Include committed changes from the current branch diff in the Composer
  status instead of reporting “No changes” when the Inspector has a diff.
- Distinguish local working-tree changes, branch diff files, commits awaiting
  push, and completed pull-request merges.
- Keep a clean new task as “No changes” and preserve the existing Inspector
  pin and automatic-collapse behavior.
- Add focused coverage for the Composer Git status state transitions.

## Validation Before Publishing

- Run desktop type checks and the complete desktop test suite.
- Confirm release metadata is `0.1.44` in the root package, sidecar, Cargo, and
  Tauri configuration files.
- Let the release workflow build, sign, notarize, and package Linux and macOS
  artifacts; inspect the draft assets and `latest.json` before publication.
