# v0.1.66 Release Notes

## macOS startup recovery

- Fix the launch failure introduced in 0.1.65: the signed application and its
  helper executables depended on Homebrew OpenSSL libraries that macOS could
  not load. Remove mobile Web Push and its OpenSSL dependency instead of
  embedding another crypto library in the app.
- Remove mobile push settings, subscription endpoints and the delivery worker.
  Retire old browser subscriptions when the service worker updates and disable
  the legacy database trigger so its notification queue stops growing.
- Mobile task creation, live conversations, history, approvals, reconnection
  and the offline shell remain available. Native desktop notifications remain.
  Mobile background push notifications are no longer available.
- macOS release validation now inspects the app and all native helpers for
  external library paths and runs a launch smoke test after signing.

## Installing over a broken 0.1.65

The macOS 0.1.65 app can crash before its updater starts. Download the archive
for your Mac from this release (`aarch64` for Apple Silicon, `x64` for Intel),
extract it, and replace **Dev Command Center.app** in **Applications**.

This is an application replacement, not a clean installation. Keep the DCC
application data directory: history, settings and pairing data are stored
outside the app bundle. Do not use an uninstaller that removes application data.
After opening 0.1.66, future releases can again use the in-app updater.
Older versions that still open can update normally.

## Validation

- Local Rust backend: 37 tests passed. Legacy push-trigger migration regression
  passed, including repeated upgrades and preserved session history.
- Mobile: 7 unit tests, type checks and production build passed. Chromium smoke
  passed task creation/recovery, offline history, reconnection, questions, diffs,
  PWA settings and removal of push controls. Subscription cleanup was checked
  with an existing subscription, an unsupported browser and an offline failure.
- Local MCP release gate, desktop type checks and production build passed.
- All four locally built macOS Rust executables link only system libraries.
  Removing Web Push removed 59 dependency packages without adding replacements.
- The new bundle check rejects the broken official 0.1.65 and accepts the
  official 0.1.64. Signed 0.1.66 archives must also pass CI signature,
  notarization and launch checks before publication.
