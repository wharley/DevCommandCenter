# v0.1.19 Release Notes

## Highlights

- Fixed the Inspector recap so it only reports that the agent is working while
  a turn is actually in flight. Once the turn finishes, the recap immediately
  returns to the relevant Git action, such as commit or push.
- Fixed the pull request conflict-resolution flow so local Git state takes
  precedence over stale forge conflict status, allowing resolved changes to be
  committed and pushed normally.

## Inspector and Git Workflow

- Distinguished an open session from an actively running agent turn by using
  the runtime active turn identifier as the authoritative working signal.
- Preserved conflict warnings while unresolved files remain in the local
  worktree.
- Allowed staged conflict resolutions to proceed to commit and local resolution
  commits to proceed to push while the forge refreshes mergeability status.
- Added regression coverage for completed turns, staged conflict resolutions,
  unresolved local conflicts, and pending resolution pushes.

## Validation Before Publishing

- Run desktop type checks: `yarn workspace @dcc/desktop typecheck`
- Run Inspector and commit-mode tests:
  `yarn workspace @dcc/desktop test workspace-recap.test.ts WorkspaceCommitButton.logic.test.ts`
- Check the Tauri crate: `cargo check --manifest-path src-tauri/Cargo.toml`
- Confirm release metadata is `0.1.19` in `package.json`,
  `sidecar/package.json`, `sidecar/src/index.mjs`, `src-tauri/Cargo.toml`, and
  `src-tauri/tauri.conf.json`.
